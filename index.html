Tangram Heightmapper (Electron Edition)

Interactive elevation data browser. Auto-exposes the display so that the highest and lowest visible elevations are white and black. The result is a grayscale heightmap, suitable for use as a displacement map in 3D applications.

Usage:

  • Uncheck "auto-expose" to set min and max height levels manually.
  • Click "export" to save the current view as a PNG heightmap.
  • Import the resulting image as a displacement map in a 3D application. (Blender tutorial)
  • The "z:x scale factor" describes how "high" the current view is, on the z-axis, in terms of how wide the current view is on the x-axis.
  • Press the 'h' key to toggle interface visibility.
